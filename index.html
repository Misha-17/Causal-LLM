1. What CLadder measures

CLadder tests causal reasoning from a described structure and supplied numerical information. It does not generally ask a model to discover a causal graph from a spreadsheet. Its generator constructs causal worlds, translates questions into language, and derives reference answers independently of the evaluated model.

The balanced v1.5 dataset contains 10,112 questions: 3,160 association, 3,160 intervention, and 3,792 counterfactual items. There are 5,056 yes and 5,056 no labels overall. A uniform random yes/no guess has expected accuracy of 50%.

The authors’ corrected Hugging Face file is full_v1.5_default.csv. Its prompt includes the actual question. The similarly named test-balanced-v1.5.csv omits question text from its prompt field. Load the corrected CSV explicitly rather than combining different dataset versions.

Dataset revision: 18d684e444ed07cc57ae0f3a91ee983a79b8119a. This identifies the checked dataset file; the supplied historical runs have not been matched to it item by item.

2. Three questions, three mathematical objects

Let X denote assistant use and Y task completion; 1 means yes and 0 means no. Association describes an observed group, intervention changes an action, and a counterfactual changes an action while retaining evidence about a particular case.

Association: P(Y = 1 | X = 1) Intervention: P(Y = 1 | do(X = 1)) Counterfactual: P(Y₁ = 1 | X = 0, Y = 0)

A structural causal model consists of background variables U, observed variables V, structural rules F, and a distribution P(U). Each variable follows a rule based on its direct causes, Paⱼ, and background factors:

𝓜 = (U, V, F, P(U)) Vⱼ = fⱼ(Paⱼ, Uⱼ)

An intervention replaces X’s rule with X := x, removing incoming arrows to X while preserving the other mechanisms. This differs from selecting cases where X already equals x.

A worked adjustment example

Suppose task difficulty Z causes both assistant use and completion. For a valid backdoor adjustment set Z, compare outcomes within each difficulty group and average using the same population weights:

P(Y = 1 | do(X = x)) = Σz P(Y = 1 | X = x, Z = z) P(Z = z)

For illustration, half the tasks are easy and half hard. Completion probabilities with the assistant are 0.90 and 0.60; without it, 0.80 and 0.40.

With assistant: 0.90 × 0.50 + 0.60 × 0.50 = 0.75 Without assistant: 0.80 × 0.50 + 0.40 × 0.50 = 0.60 ATE = E[Y | do(X = 1)] − E[Y | do(X = 0)] = 0.15

The average treatment effect is a 15-percentage-point increase. This example assumes valid adjustment and sufficient representation of both actions in each group. Conditioning on arbitrary variables can instead introduce bias: a collider is a common effect, and conditioning on it can create an association between its causes.

Calculating a counterfactual

  1. Abduction: use observed evidence E = e to update P(U) to P(U | E = e).
  2. Action: replace X’s rule with X := x, producing model 𝓜ₓ.
  3. Prediction: evaluate the alternative outcome with those updated background conditions.
P(Yₓ = y | E = e) = Σᵤ 𝟙[Y under 𝓜ₓ with U = u equals y] P(U = u | E = e)

This discrete sum becomes an integral for continuous background variables. A graph and observed probabilities do not identify every counterfactual: the supplied information and assumptions must determine a unique answer. CLadder constructs answerable problems.

3. Inputs, prompting, and scoring

For item i, the model receives question qᵢ and predicts âᵢ. The gold answer aᵢ, reference reasoning, and ground-truth metadata must stay out of its input. Accuracy is computed from the final yes/no answer:

Accuracy (%) = 100 × (number of correct answers) / (number of evaluated questions)

Rung and query-type accuracy use their own denominators. Overall accuracy is weighted by item counts; it is not generally the simple average of the three rung scores.

The supplied seven-model evaluation describes OpenRouter calls, CausalCoT prompting, and 10,112 questions per configuration. Exact prompts, decoding settings, exclusions, and per-item predictions were not provided, so these protocol claims remain unverified.

CausalCoT organizes a solution into six steps: extract the causal graph; identify the query type; express the query symbolically; collect the supplied probabilities; derive the estimand; and calculate the answer. The original paper’s implementation also uses a separate answer-extraction turn. Asking for these steps does not guarantee they are followed correctly.

Models and reasoning settings differ across the supplied configurations. The historical paper rows use gpt-4-1106-preview at temperature 0. Neither comparison isolates the effect of additional reasoning alone.

6. Error analysis

A separately supplied trace review flags three patterns. An answer flip is an incorrect final answer following apparently correct reasoning. A direction error reverses whether an effect increases or decreases an outcome. Adjustment confusion mixes valid confounder adjustment with harmful conditioning.

Same-model follow-up: forcing extra thinking on Opus 4.8

The supplied follow-up reports no returned extended thinking on 4,608 of 10,105 initial items. This does not establish that no internal reasoning occurred. Rerunning that subset with a minimum 1,024-token thinking budget raised reported accuracy from 88.60% to 90.23%.

There were 114 corrections and 39 regressions: 75 net additional correct answers, or approximately 1.63 percentage points across 4,608 items. The follow-up uses a different denominator from the main leaderboard.

7. Evidence limits and open questions

  • Unreconciled aggregates. With the stated rung counts, GPT-5.5’s subgroup scores imply 94.945% overall rather than 95.09%; DeepSeek’s imply 90.84% rather than 90.91%. Rounding does not explain these differences. Values are preserved pending the original records.
  • Missing provenance. Modern-run predictions, exact prompts, run dates, exclusions, and annotation records were not supplied. Dataset identity and scoring must be checked before treating these as independently verified findings.
  • Unknown synthetic denominators. Sample sizes and generation parameters are missing. No uncertainty intervals or statistical-significance claims are inferred from these aggregates.
  • Different protocols. Historical and modern configurations differ in model, prompting, and reasoning settings. Their scores do not isolate any one cause of improvement.

What would strengthen the evidence?

Useful follow-ups include matched paraphrases with unchanged answers; separate checks of graph interpretation, formula selection, arithmetic, and final labels; paired reasoning-budget comparisons on identical questions; and tasks that test whether a model recognizes an unidentifiable causal effect. These are proposed tests, not completed experiments.

A reproducible release should include dataset revision and item IDs, generator settings where relevant, complete prompts, exact model/provider identifiers, decoding and reasoning settings, raw outputs, answer extraction rules, retry and exclusion policies, subgroup counts, annotation guidance, and usage costs.
